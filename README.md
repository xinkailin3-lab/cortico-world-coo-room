# cortico-world-coo-room（二次元 3D 公寓 · 轻量程序化几何版）

一套零外部依赖的 **Coopanion / Cortico World v6** 扩展插件，参考现实 80–85㎡ 经典 **2LDK 动静分离两人户型**（南北通透、西动东静），使用轻量程序化卡通几何家具在本地浏览器构建二次元 3D 两人套间。

> 如果想要带有 **39 个 Kenney CC0 开源精细 3D `.glb` 家具模型**的版本，欢迎查看独立姊妹插件：[`cortico-world-coo-room-3d`](https://github.com/xinkailin3-lab/cortico-world-coo-room-3d)（两款插件 World ID、工具名与默认端口完全独立，互不冲突）。

## 核心特性
- **真实动静分离 2 人户型（6 大功能区）**：
  - **西侧动区**：北端景观阳台 → 中央客厅餐厅与过道枢纽 → 西南独立明厨。
  - **中南服务区**：独立干湿分离卫生间（带磨砂玻璃实木门、洗手台补光镜、独立玻璃淋浴房）。
  - **东侧静区**：东北独立主卧 + 东南独立双人书房，独立进出互不打扰。
- **5 扇实体可开关门 + 真实开关门过程**：
  - 主卧门、书房门、卫生间磨砂门、厨房推拉门、阳台落地推拉门，支持点击或按 `E` 键开关。
  - 桌宠沿 A* 避障路径按真实步速跨房间行走，遇到关着的门会停顿推开再通过；具备墙体/家具碰撞与三重防卡门保护。
- **2D 桌宠实时同步与双向交互**：
  - 自动复用 Coopanion 当前选中的 2D 桌宠模型（内置 Coo、大肥鱼或自定义 api v2 形象包）。
  - 360° 可旋转展览上帝视角 ↔ 室内第一人称漫游视角（WASD / 点击地板寻路），支持 24 处环境交互、气泡对话与 24 小时昼夜光照。
  - 与 Coo 共用同一套记忆与人格：房间里的聊天、摸头/戳戳与家具互动通过 Cortico 事件流同步进主会话。

## 安装与使用

### 方式一：通过 Coopanion 扩展市场安装（推荐）
1. 在 Coopanion 中打开 **设置 → 扩展 → 搜索扩展**，搜索 `cortico-world-coo-room` 并安装。
2. 重启 Coopanion，在 **World 扩展 → 我的 World** 启用 **二次元3D公寓**。
3. 在插件面板中点击 **打开 3D 公寓**（默认端口 `7890`，若端口被占用会自动顺延）。

### 方式二：本地源码安装
```bash
node tools/install-coopanion.mjs
```
（Windows 会自动读取 `%LOCALAPPDATA%\Coopanion\data-location.json` 定位数据目录；也可在末尾手动传入 `data` 目录路径。）

### 方式三：独立离线试玩
```bash
npm run standalone
```
浏览器打开终端输出的本地地址（默认 `http://127.0.0.1:7890`）。
